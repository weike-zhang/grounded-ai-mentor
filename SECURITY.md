# Security policy

## Supported version

Security and privacy fixes are applied to the latest release.

## Reporting

Open a GitHub Security Advisory for vulnerabilities that could expose learner state, project data, credentials, or execute unintended commands. Do not include real secrets or private user data in a public issue.

For ordinary teaching-quality failures, use a regular issue with a fictional or sanitized reproduction.

## Scope

This repository contains instructions and local validation scripts. It does not provide a hosted service, collect telemetry, or require an API key. Host applications and models have their own security and data-handling policies.
