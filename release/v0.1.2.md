# Grounded AI Mentor v0.1.2

This release makes learner-state validation semantics explicit and adds evidence tied to real project files.

## Changes

- a clean sensitive-data scan no longer appears as `safe_to_share`;
- consent, detected sensitive data and persistence validity are reported separately;
- state-validator behavior is covered by regression tests and CI;
- plugin metadata now matches the release version;
- the evaluation surface includes a project-grounded bundle-safety explanation with exact file evidence and an understanding check.
