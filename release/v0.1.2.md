# Grounded AI Mentor v0.1.2 — Clearer learner value and consent-safe state checks

This release makes the learning outcome understandable before the teaching protocol, separates sensitive-data scanning from user permission, and adds a candid comparison grounded in real public project files.

## What changed

- Rewrites the English and Chinese first screen around recognizable learner problems, observable outcomes and a concrete port-learning example.
- Removes the misleading `safe_to_share` result and reports consent, detected sensitive data and persistence validity separately.
- Adds regression tests for blank state, explicit consent and sensitive-data rejection without echoing matched content.
- Adds a second exploratory comparison that cites a real release bundler, tests and documented failure with permanent source links.
- Updates both comparison visuals so the baseline and Skill sides show the same learner task in user-readable language.

## Install or update

```bash
npx skills add weike-zhang/grounded-ai-mentor --skill grounded-ai-mentor -g
```

## Verification

- `python3 -m unittest discover -s tests -v` — all state-validator regression tests passed.
- `python3 evals/validate_fixtures.py` — all fixture-integrity scenarios passed; this is not a model-quality score.
- Local link, redacted secret and strict public-surface checks completed with no findings.
- The blank learner-profile template remains unauthorized for persistence even when its structure and sensitive-pattern scan pass.

## Compatibility

- Skills CLI repository discovery is verified for the `grounded-ai-mentor` Skill.
- The bundled validator is verified with Python 3.12 in GitHub Actions.
- Other Agent Skills hosts remain unverified; compatibility reports are welcome.

## Known limitations

- The two published comparisons are exploratory pairs, not a benchmark or proof of long-term learning gains.
- The project-grounded pair showed a clearer system path but no material accuracy advantage over an already strong baseline.
- A clean configured-pattern scan does not grant permission to persist or share learner state.
