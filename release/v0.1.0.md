# Grounded AI Mentor v0.1.0

The first public release packages a zero-assumption, project-grounded computer science and AI mentor as an Agent Skill and a Codex skills-only plugin.

## Included

- A six-part protocol for defining new technical terms.
- Separate explanation, diagnosis, implementation and planning routes.
- Evidence rules for real-project claims.
- Proportionate understanding checks and misunderstanding recovery.
- Consent-based local learner state and a redacted safety validator.
- Bilingual documentation, fictional examples and a structured Eval suite.

## Known limits

- Long-term learning gains have not been established.
- Live behavior varies by host and model.
- Compatibility outside the locally validated formats remains unverified until raw community runs are available.
- The mascot is approved for this project's public repository and Release, but is not separately licensed under MIT for reuse outside Grounded AI Mentor.

Please report reproducible failures with sanitized inputs and the host/model context.
