# Grounded AI Mentor 传播方案

## 当前传播目标

首发不以“星标越多越好”为唯一目标，而是优先获得：

1. 能完成一次真实教学对话的试用者；
2. 能指出具体教学失败的高质量反馈；
3. 愿意复现评估或验证其他客户端兼容性的贡献者。

## 可公开证据

- 火焰角色和清楚的 Hero，建立识别度；
- “普通回答 / Grounded AI Mentor”差异表；
- 24 条触发夹具、8 个教学场景和 100% 材料覆盖验证；
- 一组带 Skill / 不带 Skill 的探索性行为对照；
- 本地状态、明确同意、可查看/纠正/删除的隐私设计。

## 最小有效传播组合

### 主入口：GitHub README

所有外部内容只指向一个仓库入口。首屏回答“它解决什么、为什么不同、怎样立刻试一次”，随后给证据、隐私边界和贡献入口。

### 主内容：一次可复现的前后对照

使用“我还是不懂端口”案例，展示基线与 Skill 在最早前置概念、系统路径、通用示例标注、理解验证上的差异。发布原始提示词、环境和限制，不只发分数。

### 反馈路径：具体失败 Issue

要求试用者提交一种可复现失败：未定义术语、编造项目关联、过早修改、没有找到最早缺口，或学习者无法迁移。让反馈成本低于泛泛写长评测。

## 何时增加渠道

- 已有 3 个可复现试用反馈后，再写一篇中文长文总结真实失败与修改；
- 已有英文试用者或贡献者后，再扩展英文社区；
- 有稳定、可重复的行为对照后，再制作短视频或动图；
- 没有新证据时，不为“保持活跃”重复发布同一套宣传。

## 衡量

记录：仓库有效访问、首次成功调用、完成一轮教学、可复现 Issue、兼容性验证、贡献合并和维护成本。星标只作为传播漏斗的一个弱信号，不作为教学价值证明。
