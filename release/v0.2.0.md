# Grounded AI Tutor v0.2.0 — The tutor comes first, and project evidence stays optional

v0.2.0 renames the project and Skill from Grounded AI Mentor to Grounded AI Tutor. The README now starts with the tutor's lasting job: find the first prerequisite an explanation skipped and teach from there without assuming a technical background. Real project evidence remains available when it improves a lesson, but it is no longer presented as the product's main identity. This release also separates sensitive-data scanning from consent and publishes a second project-grounded comparison without claiming an accuracy win.

![The same port question answered normally and with Grounded AI Tutor](https://github.com/weike-zhang/grounded-ai-tutor/raw/v0.2.0/assets/before-after.png)

## Should I update?

**Update now if:**

- You want the tutor-first `grounded-ai-tutor` name and invocation instead of the older project-first identity.
- You use or review `.grounded-ai-tutor/learner-profile.md`; v0.2.0 removes a result that could be misread as permission to persist or share the file.

**You can defer if:**

- You only read the historical teaching examples and do not install the Skill; those examples remain available in v0.1.1.
- You need benchmarked learning outcomes or verified support across Agent Skills hosts; this release does not establish either.

## What changed

- Renames the project, repository target and Skill ID to Grounded AI Tutor and `grounded-ai-tutor`.
- Rebuilds both README openings around the tutor's core job and presents project evidence as an optional teaching mode.
- Removes the misleading `safe_to_share` result and reports consent, detected sensitive data and persistence validity as separate facts.
- Adds regression tests for blank state, explicit consent and sensitive-data rejection without echoing matched content.
- Adds a second exploratory comparison that cites a real release bundler, tests and documented failure with permanent source links.
- Updates both comparison visuals so the baseline and Skill sides show the same learner task in user-readable language.
